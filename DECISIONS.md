# Gable — decision log

Every design decision, with the reason it was made. **Append-only.** When a
decision reverses, add a row saying so and why; never edit an old row away.
The reversals are the reason the next agent does not repeat the week that
proved them.

This lived in `ARCHITECTURE.md` §9 until 2026-08-13, when that file reached the
800-line ceiling `tests/test_repo_standards.py` enforces. The log is the part
that grows forever, so it moved here.
