# Natural-language Slack and release audit

Date: 2026-08-13

## Outcome

Slack is now natural-language only. Gable has no slash-command declaration,
OAuth command scope, Bolt command handler, command service, operator retry
queue, or user-controlled polling pause. Carmen and Chase begin with an
`@Gable` mention and continue with ordinary replies inside the thread Gable
owns. A narrow natural-language rebuild action remains for a paused listing or
corrected source template; it resumes the same run and never bypasses the
three-attempt ceiling.

The command surface existed because the earlier runtime specification
explicitly required status, forced polling, retry, template listing, pause, and
resume operations. It was an implementation of that specification, not a Slack
or pipeline requirement. Chase rejected the operator-console workflow, so the
decision was reversed and the entire Slack-facing implementation was removed.

`tools/run_row.py` remains. It is a developer-only release-test tool run on the
droplet, not a Slack feature and not something Carmen or Chase must use in the
product. It is the controlled way to exercise an already-existing form row
without weakening the poller's historical-row and duplicate-run guards.

## What changed

- Deleted `slackapp/commands.py` and its test module.
- Removed `/gable` registration from the Bolt app and removed command assembly
  from the production runtime.
- Removed the poller's process-local pause, forced-pass, queued retry, queued
  resume, and last-poll command state.
- Removed database queries that existed only for the command status display.
- Removed `features.slash_commands` and the `commands` bot scope from
  `slack/manifest.json`.
- Applied the same manifest to Slack app `A0BNWTFQ4KZ`. Slack confirmed the
  save; the live Slash Commands page contains no configured command and the
  bot-scope list contains no `commands` scope. Slack did not request a
  reinstall because the permission set only became smaller.
- Replaced command-oriented documentation with the owned-thread conversation
  contract and added `TESTING.md` as the repeatable verification guide.

## Bug review

The review covered the form reader, poller, run state transitions, template
catalogue and preflight, Slides copy/fill/readback, hero and headshot placement,
photo handoff, final render inspection, Slack routing and ownership, native
waiting state, natural-language actions, configuration, and deployment
surfaces. Ruff, strict Mypy, Pytest, Vulture, dependency integrity, diff
integrity, and source-file size checks were run after the changes.

Two defects were found and fixed:

1. A visual provider could return a confident negative verdict with an empty
   `problems` array. The runner extended an empty list, leaving no blocking
   problem and incorrectly allowing delivery. A negative visual verdict now
   always creates a review problem, with a regression test proving it cannot
   silently deliver.
2. The deterministic rebuild phrases accepted “can you rerun this project” but
   did not accept Chase's exact sentence, “Hey, can you rerun this project?”
   because the greeting remained after punctuation normalization. The parser
   now removes one ordinary greeting before matching the same narrow action
   phrases. The full gate caught this before deployment.

No other high-confidence dead production function was found. No dependency is
broken, no current command registration remains, and no checked Python file
exceeds the 800-line ceiling.

## Built, dormant, or deliberately not connected

| Capability | Current truth |
|---|---|
| Synthetic property images | Only compatibility policy and audit state remain. No generator, approval flow, or runtime call exists. |
| Automatic property-photo discovery | Drive-property folders, brokerage sites, web search, and MLS lookup are not connected. Gable uses one image supplied in its owned Slack thread. |
| Brokerage URL cache | This belongs to the future web-photo resolver and is not built. |
| Second-model visual consensus | Researched but not connected. It needs a representative evaluation before adding another paid and potentially conflicting verdict. |
| Saliency or focal-point crop retry | Not connected. Crop loss is measured and the completed render is inspected, but Gable does not automatically choose a new focal crop and render twice. |
| Run-event history viewer | Every transition is recorded in `run_events`; there is no user-facing console over that ledger. |
| Two-agent role placement | Listing and hosting roles parse, but sources do not yet carry a certified per-role object map. The runner stops before copying. |
| Generic missing-info persistence | A free-form answer is not written back to the form or contact workbook. The human fixes the authoritative source and asks in the owned thread to check again. |
| Photo-host retention | Derivatives are content-addressed, but no pruning or retention job exists. |
| Legacy salesperson columns | Compatibility columns remain in SQLite; current template routing, headshot lookup, and contact sync use their newer authoritative sources. |

The former slash command, polling pause, operator queue, and command-only status
queries are not dormant; they were deleted.
